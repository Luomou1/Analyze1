# 白光干涉重建

保留原有桌面界面、干涉图读取、扫描步长输入，以及独立的平面分析和台阶分析。算法下拉框为 Normal、High、High 2G，入口为 `app/reconstruction/engine.py`。旧 FDA、GFDA、lg 与 DLL 模式 2 的应用计算代码已移除。

## 启动与使用

在本目录运行 `python main.py`。选择干涉图目录，按相机数据格式选择强度模式，输入扫描步长（单位 μm）。50 nm 应输入 0.05。载频预览不是正式分析的前置条件；正式计算由每个像素的有效频谱确定载频。自动选取有效扫描范围，FFT 使用该范围的实际帧数，不固定为 64 帧。

Normal 输出相位斜率高度；High 使用独立的相位偏差直方图、局部载频细化及区域残差处理；High 2G 使用整数相位域区域连接。三种模式均从 `reconstruction` 包调度，像素诊断使用同一频谱与拟合函数。输出高度单位为 nm，无效点为 NaN。

## 原厂对照范围

参考本机 MetroPro 10.0.5 的 `Micro.app` 模式映射及 MetroPro.exe。Normal=0、High=1、High 2G=3；不能把 DLL FringeOrderAnalysis 模式 2 当作 EXE High。

已直接调用原厂 EXE 辅助函数生成回归数据，覆盖三点频谱拟合、High 相位直方图、残差平面与直方图扣除、边缘剔除和区域展开。`tests/data/exe_*` 保存原厂输出；研究脚本和反汇编位于上级 `tmp/metro_evidence`。

**当前实现尚不等于原厂软件的完整复现。** 公共前端采用实际 N 帧和浮点强度适配，峰帧选择与原厂采集缓冲路径尚未完成整体等价验证；High 全流程和 High 2G 的材料／系统色散标定、其他配置分支仍未完成原厂端到端比对。High 2G 当前实现为单材料无色散标定路径。辅助函数对照通过及样本运行成功，不能替代整条算法原厂结果一致性的证据。

## 验证

运行 `python -m pytest -q`。测试包含新重建层、像素切换、界面、输入输出和独立表面分析。用户提供的 Round_01 样本已通过三种模式完整读取与计算；201 张输入图自动选择 31–133 帧，共 103 帧。原厂同输入整图输出尚未取得，不据此声称原厂精度一致。

## 解包裹与频点窗口

解包裹下拉框提供 EXE 从左向右展开和 unwrap1。unwrap1 以功率峰为起点向两侧展开，撤销中心化相位后拟合；高度接口显式转换回中心化系数，避免重复恢复参考。像素诊断还撤销信号循环移位，显示原扫描参考下的展开和拟合相位。unwrap1 是用户指定方法，不标为原厂分支。

“左右各取频点数”默认 3，即主峰加左右各 3 点，共 7 点；两种解包裹都使用这个用户窗口。边界及零功率／无效点可能减少实际点数，至少需要 3 点且峰两侧有点。功率门限保留用于主峰有效性检查，不再决定窗口宽度。正式计算与像素诊断使用本次运行的同一参数快照。

## 公共 K0 显示

主界面“计算公共 K0”使用与正式计算相同的扫描帧段、位深、解包裹及左右频点数，平均全部有效像素的插值峰位置。原汇总幅值频谱找最大点的预览 K0 已替换。频谱曲线只提供背景显示，标记位于公共 K0 的精确浮点坐标。正式分析完成也会更新公共 K0 数值；像素窗口仍显示当前像素的局部插值 K0。

## 手动公共 K0

High 2G 的公共 K0 输入框可编辑。未编辑时，每次正式运行按当前有效像素自动统计；手动改为正数后，正式运行使用该值完成相位高度、周期尺度和后续连接计算，普通分析完成不会覆盖手动值；主动点击计算公共 K0 且成功后，会更新输入框并恢复自动模式。输入 0 恢复自动。像素窗口仍显示局部插值峰，不被公共 K0 覆盖。Normal 的斜率高度不使用公共 K0，High 保持自己的局部载频流程。

原厂 DLL 的 PhaseAlgorithmFda::PostProcess 在调用 FringeOrderAnalysis 之前已完成公共载频相位高度计算和半周期级次选择。FringeOrderAnalysis 的模式0在0xE6560跳转表中指向0xE6546直接返回；直接调用原厂函数确认输入粗细高度与输出缓冲均不修改，状态为0。这证明存在关闭后处理的配置路径，不代表已确认其官方界面名称。本次仅调研，尚未新增此工作流。

## High1G

工作流下拉框新增 High1G（本项目命名，不声称是原厂界面名称）。它使用当前频谱前端逐像素拟合，自动统计或手动指定公共 K0。在公共频率处求各像素的拟合相位，换算相位高度，再以 π/K0 为高度周期加减整数级次，使结果与斜率高度的差位于闭区间 [-π/(2K0), π/(2K0)]。恰好正负半周期时不移动。

High1G 在此直接输出 h_prime，不执行平滑、滤波、区域连接或残差平面处理。h 仍为斜率高度；phi0 为公共频率处的拟合相位。支持 EXE / unwrap1 和左右频点数。当前实际 N 帧前端的原厂等价性限制仍然存在，不能将本分支宣称为完整原厂 DLL 位级复现。

## High 2G 额外诊断图

结果预览区提供“显示额外诊断图”按钮。每次新结果默认隐藏七张 High 2G 专属诊断图及诊断摘要，首次点击才创建画布并绘制，按钮可再次隐藏。主高度图和原有三维图继续显示。此功能减少诊断绘图开销，不跳过高度重建所需的滤波、连接计算。

Auto 由 EXE `FilterMgr::getFilterParams`（RVA 0x544320）确认：以输入矩阵短边 N 为基准，低截止 10/N、高截止 30/N cycles/pixel；FFT 再按补边尺寸量化到最近频格（0x9EF8F0），样条不量化。它是起始截止，不是从噪声谱寻优。界面运行后显示实际值，分析结果保留完整参数快照；尺寸不足、截止达到不支持的采样范围时明确报错，不擅自更换截止。

Sinusoid 不是理想硬圆掩码。DLL 在轴线频格使用圆与格点的解析交面积，内部边界格使用交点弦组成的多边形面积；对应 RVA 0x1B13C0～0x1B2A50。该差异已通过 32 个矩形、NaN、台阶、随机噪声、单/双频样例验证。截止按 EXE 检查必须落在第 1 个频格至 Nyquist 前一格，避免底层库在 Nyquist 边界存在的未初始化频格；超界报错，不生成随机结果。频率滤波 Trim 来自主程序 FilterMgr 对 0x986830 的调用：滤波后裁 5 层外部边缘，逐层重新判断内孔是否与外部连通。固定 EXE 工件覆盖内部孔洞、凹边及孔洞在裁剪中连到外部的情况；不再套用窗口滤波的完整邻域规则。

固定球面需要非零半径（mm），正表示凸、负表示凹；按 SphereFitter 固定半径分支最小化径向距离误差，拟合球心后生成精确球面高度。锥面输入全锥角（度），正凸负凹，范围 ±5～±180；自由角度可输入 0。锥面拟合顶点、两个倾角，自由分支另拟合锥角；按 DLL 的射线求交方程最小化竖直高度误差。固定 180° 为平面极限。高级形状拟合必须填写横向标定，应用高度 nm 在拟合前转为 μm；球面系数为球心 XYZ 和有符号半径（μm），锥面系数为顶点 XYZ（μm）及 alpha/beta/gamma（弧度）。无效域、退化分布、无交点或未收敛明确报错。

新增工件为 `surface_sinusoid_native.npz`、`surface_filter_control_native.npz`、`surface_sphere_native.npz`、`surface_cone_native.npz` 及 JSON，生成器分别为 `fft_fixed_probe.py`、`filter_control_probe.py`、`sphere_probe.py`、`cone_probe.py`。球面/锥面来自原厂拟合及去除分支，覆盖凸凹、偏心、倾斜和 NaN。非线性求解器与原厂停止条件不同，测试绝对残差容差为球面 0.00002 nm、锥面 0.002 nm（对应固定测试尺度），不是位级一致或全部尺度精度保证。Auto 常数由静态调用证据确认，矩阵短边、FFT 频格量化和 Trim 辅助函数另做动态调用；不将这一证据描述为整个 EXE UI 端到端验证。

## 平面与台阶交接事项更新（2026-09-22）

横向标定默认保持用户指定的 0.48 μm/pixel，X/Y 共用；不是本次重新标定，也不是 Z 扫描步长。用户已明确暂缓标准平面、已知高度台阶的实测验收。

处理顺序已改为 **Trim、去尖峰、Min Area Size、滤波（含 Filter Trim）、去形状、Data Fill、统计**。证据来自 MetroPro 10.0.5 EXE 的 PhaseContext 方法表：`preZernikeProcess:errorMessageSTR:` 位于 RVA 0x251B80，依次在 0x25261F 调用 Trim（0x986830）、0x2526F9 调用去尖峰（0x9EF6C0）、0x252785 调用区域筛选（0x99C510），随后经 selector +0x308 调用 `filterData:errorMessageSTR:`（0x250890）。`process`（0x252900）通过 selector +0x368 调用前述预处理，随后执行形状拟合/扣除，0x254D47 调用补洞（0x985410）。初始化函数 0x244030 中对应字段为 Trim +0x308/+0x310、Spikes +0x2B0/+0x2F0、Min Area +0x2A0、Data Fill +0x210/+0x208。反汇编均保存在上级 `tmp/metro_evidence/metro_140*.asm` 并带模块哈希。Micro.app 的 Data/Map/Profile 使用多个数据窗口层级，故这项证据限定为已定位的 PhaseContext 常规分支；特殊裁剪、脚本、自动孔径、父子窗口叠加尚不能据此称为全部 UI 路径等价。EXE 本身未直接导入 Analysis.Core 数值算子，Interop 的导出包装不能作为整个 EXE 调用链已验证的证据。

`surface_chain_native.npz` 保存 8 组按该顺序组合调用原厂 DLL 算子的逐阶段矩阵，覆盖 Trim All/Outside、尖峰、平均滤波、平面扣除和补洞；每阶段检查高度及 NaN 掩码，绝对容差 1e-9 nm。Min Area=0 的组合固定工件与单独区域筛选工件分开验证，另有裁剪/区域筛选/补洞交互测试。它们是静态顺序证据加离线组合对照，**不是在 MetroPro UI 中加载相同文件取得的端到端输出，也不是实测计量验收**。

Data Fill 新增限面积内部孔、全部内部孔、包含边界孔三种范围，以及 Polynomial 与 Differential 两种算法；默认仍为关闭、限面积 Polynomial。Polynomial 先补四邻均值的孤立点，再按面积从大到小拟合局部二次面，补值参与后续拟合；拟合退化时使用有效边界包围框均值。边界包围框的扩张方式与原厂一致。原厂 `SetMaxFillSize` 会重置 Mode 为 0，因此探针必须先设置 Max 再设置 Mode；旧探针中所谓多个模式实际都运行限面积分支，旧工件仍可用于该分支。`surface_fill_boundaries_native.npz` 新增 96 组真正独立模式对照，覆盖相邻/对角孔洞、Max=0/1/4/25、边界孔、跨台阶孔与退化边界。

DifferentialFiller 使用四邻 Laplace 原位行优先松弛，初始化为有效边界均值，停止阈值为边界 PV 除以孔面积；松弛系数按面积小于 100/1000/10000/100000/更大分别为 1.5/1.6/1.7/1.8/1.9。依据为 0x21C3D0、0x21CD10、0x21CAC0；边缘采用反射邻点。`surface_differential_native.npz` 的 96 组默认参数对照容差为 1e-9 nm。应用额外设 100000 次迭代上限，超限报错，不返回未收敛结果；此上限不声称是原厂停止规则。其他原厂自定义容差/松弛参数尚未开放。去尖峰的图边邻域同时修正为向内平移的完整 3×3 窗口，再减去当前点，依据 0xE7BF0；原来的截断邻域会漏掉边缘差异。

台阶页面现在提供两个框选平台各自的 Sa/Sq/PV、有效点数量和比例，可选处理后共同零基准、各自均值面、各自独立拟合平面。默认各自均值面。独立平面为区域局部像素坐标下 `z=a*x+b*y+c`，退化或共线区域明确提示无法拟合。平台参考面只作用于平台指标，台阶高度仍为处理后区域一均值减区域二均值；不把平台高度差消掉。全域指标仍相对零基准，并明确包含台阶高度差，不代表完整 ISO 25178 评价。
